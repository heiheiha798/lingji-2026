# 优化说明

## 优化思路

实现保留双缓冲 Jacobi 稳定化，以保证任意尺寸和输入分布下的精确结果。
每个 sweep 仍批量处理当前高度中的全部合法倒塌次数，但只有 `q != 0` 的
格点才读写 64 位 odometer，避免稳定区域在数千轮传播中反复产生无效的
16-byte 读改写流量。

高度双缓冲使用 32 位无符号整数。输入高度不超过 `UINT32_MAX`，而一次
Jacobi 更新的上界为
`3 + 4 * floor(UINT32_MAX / 4) = UINT32_MAX`，因此每一轮都保持该上界，
不会发生截断或溢出。相比 64 位高度，这使每轮五次邻域读取和一次输出写入
的字节数减半。

终止检测每 16 个 sweep 执行一次。稳定状态是 sweep 的不动点，因此额外
sweep 不会改变 stable 或 odometer；这一批处理减少了 device-to-host 标志
传输、stream 同步、清零和全局原子写。带终止检测和不带终止检测的 sweep
由编译期模板分别生成，普通 sweep 中不保留原子分支。

RTX 4090 物理 GPU 7 的完整公开单次验收中，随机 5 组与固定 6 组全部通过。
P1 至 P5 用时分别为 396.935、3970.809、6482.367、6512.743 和
24063.923 ms；相对随包 reference 的加速为 1.898x、3.815x、3.714x、
8.541x 和 3.956x。

无。
