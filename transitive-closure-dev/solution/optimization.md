# 优化说明

## 优化思路

实现采用 64 位 bitset 的 blocked Warshall。每轮先在一个 64 x 64 子块内求
完整闭包，再据此生成 64 条闭包后的 pivot 行，最后用一个 kernel 将这 64
个 pivot 一次应用到所有行。块间仍严格保持 Warshall 的先后依赖，块内则把
原来 64 次全矩阵扫描和 kernel 启动合并为一次扫描，显著降低启动开销。

设备端直接把输入上传到闭包矩阵，不再额外保存一份邻接矩阵，也省去一次
device-to-device 全矩阵复制。临时存储仅包含 64 条 pivot 行和 64 个块内
可达 mask。

## 额外依赖

无。
