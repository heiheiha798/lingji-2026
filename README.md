# 2026 "灵玑杯"高校算力系统软件邀请赛

本仓库用于完成 2026 "灵玑杯"当前公开的高性能计算、TileLang 和 AKO 赛题。

官方信息来源：

- [赛事官网与奖项设置](https://tlaic.ac.cn/competition)
- [参赛须知](https://competition.tlaic.ac.cn/terms)
- [赛题与数据下载](https://competition.tlaic.ac.cn/problems)
- [评分与最终排名](https://competition.tlaic.ac.cn/ranking)
- [公开赛题列表 API](https://api.tlaic.ac.cn/problem/list)

本文档按 2026-08-10 的官方页面整理。赛题和规则可能继续更新，提交前应再次核对官网。

## 参赛资格与纪律

- 仅面向北京大学、北京航空航天大学、北京邮电大学、北京师范大学在校生，使用本校邮箱注册。
- 比赛仅限个人参加。每人只能使用一个账号，禁止组队、代答、重复报名或使用他人账号。
- 比赛完全结束前，禁止公开、交换或索取解法、提示和答案。
- 获奖代码将接受审查，组委会可以要求选手说明实现思路。
- 登录后须通过准入测验，成绩达到 60 分才能申请算力并上传代码；三次未通过会锁定算力与提交权限。
- 每道题最多提交 20 次，单次提交大小上限为 100 MiB。
- 比赛提供的算力仅限比赛用途；不得攻击竞赛平台或利用漏洞影响公平性。

## 参赛模式

选手选择以下一种模式：

1. **基础赛道 + 专项赛道**：必须参加高性能计算基础赛道，并至少参加 TileLang、AKO、xLLM 中一个专项赛道。
2. **专项赛道**：至少参加 TileLang、AKO、xLLM 中一个专项赛道，不强制参加基础赛道。

各赛道独立命题、独立排名、独立评奖。未参加的赛道在综合总榜中不加分，也不扣分。

## 评分规则

### 高性能计算基础赛道

每道题的每个测试点由两部分组成：

- 正确性：50%。
- 性能：50%。性能分以该测试点全体选手的最短耗时为基准，按 `T_min / T_i * 100` 归一化。

最终名次按所有基础赛道题目、所有测试点的累计得分确定。因此，虽然规则没有要求必须完成全部题目，但缺题会直接损失累计分数；以获奖为目标时应覆盖全部基础赛道题目。

### 专项赛道

TileLang、AKO、xLLM 根据以下指标综合评分并独立排序：

- 客观指标：性能、正确性等。
- 主观指标：创新性、工程实现质量、技术报告质量等。

### 基础赛道特色奖

该奖项面向选择“基础赛道 + 专项赛道”模式的选手。需要在基础赛道题目中创新性地融合 TileLang、AKO 或 xLLM 技术并取得优秀效果，由专家评审委员会综合评定。

## 终极挑战荣誉

所有选手自动进入综合总榜：

> 综合总积分 = 各赛道名次积分之和 + 特色奖总积分

| 排名或奖项 | 积分 |
|---|---:|
| 单赛道前 5% | 10 |
| 单赛道前 5% 至 10% | 8 |
| 单赛道前 10% 至 30% | 6 |
| 其他顺利完赛者 | 2 |
| 每个特色奖 | 3 |

综合总榜设置钻石 1 名、白金 3 名、黄金 5 名，奖励为奖杯和奖品。规则不要求完成所有题目或参加所有赛道，但参加更多赛道并取得有效名次通常能获得更高综合积分。

## 本地开发约束

- GPU 测试仅允许使用物理 GPU 6 和 GPU 7。
- 不得未经确认添加 fallback 或兜底实现。
- Kernel 候选通过 correctness 且 cold-L2 timing 或 NCU 出现明确正向信号后，先保存 checkpoint commit，再继续结构优化。
- Synthetic、本地噪声测试和官方评测结果必须分开记录。
